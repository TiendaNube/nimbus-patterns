# `@nimbus-ds/bottom-sheet`

[![@nimbus-ds/bottom-sheet](https://img.shields.io/npm/v/@nimbus-ds/bottom-sheet?label=%40nimbus-ds%2Fbottom-sheet)](https://www.npmjs.com/package/@nimbus-ds/bottom-sheet)

A mobile-first modal sheet that slides up from the bottom edge, with configurable snap points and a pointer-driven drag gesture to resize between them or dismiss by dragging down.

## Installation

```sh
$ yarn add @nimbus-ds/bottom-sheet
# or
$ npm install @nimbus-ds/bottom-sheet
```
