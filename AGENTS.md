## Live Local Preview with Admin (`services-new-admin`)

To see local pattern changes reflected immediately in `services-new-admin` (`packages/stratus`) without publishing RC packages or editing `package.json`:

1. **Pattern `.tsx` changes (`packages/react/src/**`, including `/next`):** Resolved directly from source by Stratus Vite when `NIMBUS_LOCAL=true` (< 200ms Fast Refresh, no build required).
2. **Adding a new `/next` pattern directory (`packages/react/src/next/<Pattern>`):** Run `yarn watch:admin` (or `yarn generate:next-index`) in this repo so `packages/react/src/next/index.ts` updates automatically.
3. **In `services-new-admin`:** Start with `NIMBUS_PATTERNS_PATH="<abs-path-to-this-repo>" yarn start:front:nimbus` (or `yarn start:dev:nimbus`). Always pass `NIMBUS_PATTERNS_PATH` explicitly when working inside a Claude Desktop (`.claude/worktrees/...`) or Codex Desktop (`~/.codex/worktrees/...`) worktree.

Full workflow in `.agents/skills/nimbus-admin-live-preview/SKILL.md`.

## Key Rules

- **Never hand-edit `packages/react/src/next/index.ts`:** It is auto-generated by `yarn generate:next-index` (`.scripts/generate-next-index.ts`).
- **Keep `nimbus-source-map.yml` up to date:** If you add or rename files under `packages/`, run `yarn source-map` and verify with `yarn source-map:check`.
- **Base invariance:** Changes for Norte UI (`next-norteui` / `next-norteui-dark` or `/next` patterns) must preserve 100% invariance for `base` and `dark`. Verify with `yarn check:base-invariance`.

## Common commands

```bash
yarn build                  # generate:next-index + build:packages --all
yarn watch:admin            # watch /next pattern directories for live Admin preview
yarn generate:next-index    # regenerate packages/react/src/next/index.ts
yarn check:base-invariance  # verify base/dark invariance
yarn source-map:check       # verify nimbus-source-map.yml is up to date
yarn lint                   # eslint over packages
yarn test                   # jest
yarn types:check            # tsc --noEmit
yarn storybook              # local storybook on :6006
```
